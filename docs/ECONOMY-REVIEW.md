# 经济系统审查(2026-07-25)

起因:玩家反馈「钱一直在不停增加」。用计数器逐口径实测(挂机 30 秒、按来源拆账),
结论:**两个 bug + 一个设计缺陷叠加**。本文记录实测数字、已修项与遗留建议。

## 已修

### 1. [BUG] 兵营/坦克厂产能上限失效 → 单位无限增殖
上限判据 `islandStructures(isl,team,'soldier')` 按「此刻站在岛上的」计数,而士兵产出后会
离岛作战,立刻不再被计入 → 兵营永远认为没到上限。实测:上限 7 的岛上存在 27 个士兵,
纯陆战关全场 900+ 单位。修复:单位创建时记录出生岛 `homeIsl`,上限按出生地计数。

### 2. [设计缺陷→已改] 击杀赏金无归属——谁打死的都给玩家全额
`killLandUnit`/`damageTarget`/`killAIPlane`/`critHurt` 的赏金只看目标是敌方,不看是谁打死的。
纯陆战关玩家**一枪不开挂机**实测:**$7,680/分钟**(全部来自友军 AI 的战果)。

改法(归属模型):玩家自己的火力(炮弹 `playerCausedShell`、爆炸波及、直接命中)在
**10 秒内**碰过的目标,击杀付**全额**;纯友军战果付 **25% 舰队分成**。
击杀计数(教程/成就/战报)不受影响,只改钱。

| 场景 | 改前 | 改后 |
|---|---|---|
| 陆战关挂机收入 | $7,680/min | **$710/min** |
| 玩家击杀士兵 | $50 | $50 |
| 纯友军击杀士兵 | $50 | $13 |
| 友军击沉驱逐舰 | $350 | $88 |

## 遗留观察(建议,未改——涉及手感,由 Andy 决定)

3. **结构击杀赏金表偏高**:核弹发射井 $8,000(≈11 艘驱逐舰),即便按 25% 分成,友军拆一座
   也进账 $2,000。建议压到 $500–1,500 区间。
4. **岛屿被动收入**:$2/秒/岛。10 岛 = $1,200/分钟,长局里超过战斗收入。建议 $1/秒或设总量上限。
5. **护航送达事件 +$900**:一次≈2 艘舰的击沉赏金,偏高,建议 $400–500。
6. **钱没有出口**:修理免费、换船免费、增援免费,后期收入又随战区规模膨胀——中后期金钱失去
   意义。方向性建议(新玩法,应由 Andy 拍板):付费召唤增援舰队 / 港口快修收费 / 战略武器弹药费。
7. 秘籍键 `\` ×3 = +$10,000 仍然存在(开发后门)。注意不要出现在推广文案里。
